# TMLR revision package

This directory contains the anonymous TMLR revision of *Measuring Finite-Budget Coordination-Collapse Crossings in Reward-Mixed Cooperative MARL*.

- `build/main.pdf` is the checked 19-page manuscript.
- `main.tex`, `content/`, `references.bib`, and the selected files in `generated/` are the exact source inputs used to compile that PDF.
- `artifact/TMLR2026_anonymous_artifact.zip` is the manifest-checked reproducibility archive. It contains the per-run evidence, immutable executed-source snapshot, analysis environment lock file, and a one-command clean rebuild.
- `audit/REVIEW_RESPONSE_MATRIX.md` and `audit/SUBMISSION_CHECKLIST.md` record completed work and remaining submission blockers.

The prospective optimizer/normalization factorial is frozen separately under `AAMAS2027/optimizer_factorial_v2/`; its source snapshot is under `AAMAS2027/optimizer_factorial_source_v2/`. It is explicitly unexecuted and contributes no reported result.
