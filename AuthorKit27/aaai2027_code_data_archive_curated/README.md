# Anonymous AAAI-27 Code and Data Archive

This archive contains the anonymized code, run scripts, result CSVs, run maps, and generated figure artifacts needed to audit and reproduce the paper's tables and figures.

- `agents/`, `env/`: environment wrappers, reward transforms, and learner components.
- `experiments/`: training, analysis, robustness, and figure-generation scripts.
- `run_*.pbs`: batch scripts used for the reported sweeps.
- `docs/`: curated result directories for the main paper and supplement; each directory contains raw per-run CSVs, run maps, summary files, or generated figures.
